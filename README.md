# TeroClass

AI-powered didactic planning platform for teachers.

## Setup

1. Deploy to Vercel
2. Open the app and click ⚙ Azure OpenAI Settings
3. Enter your Azure OpenAI credentials:
   - Endpoint: your Azure OpenAI endpoint
   - API Key: your Azure API key
   - Deployment: gpt-4o
   - API Version: 2024-12-01-preview

## Tech Stack

- Vanilla HTML/CSS/JS frontend
- Vercel serverless API proxy (avoids CORS)
- Azure OpenAI (gpt-4o)
